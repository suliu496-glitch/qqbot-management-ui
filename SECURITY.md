# Security Policy

If you find a security issue, do not post API keys, QQ identifiers, logs, database files, screenshots containing personal data, or other secrets in a public issue. Reproduce with synthetic data and report only the minimum technical details needed to maintainers through a private channel they designate.

This repository is currently a local Windows bot release. Do not expose the management UI or OneBot endpoints to the public Internet. The OneBot client does not yet support a shared access token in this release.
